# ppt-deck — 图片型 PPT 生成

## 概述

每页是一整张由图片模型生成的 16:9 幻灯片图，风格统一、排版精致，最后组装成 `.pptx`（含演讲备注）供用户下载。创意部分（提纲 + 每页出图提示词）由你负责，机械部分（逐页出图 + 组装）由 `generate_ppt` 工具负责。

## 流程

1. **理解素材，定主题**。用户给了资料就读（`terminal`/`vision_analyze` 读上传文件/图片），没有就据其需求拟主题、受众、页数（一般 8-12 页）。
2. **选风格**。用户指定了预设风格就用；上传了风格参考图就先 `vision_analyze` 提炼其视觉语言、再挑最接近的预设；没指定就默认 `科研答辩风`。可用预设：
   科研答辩风、麦肯锡风格、清爽专业风、数据仪表盘风、党政红风格、教学课件风、温暖手工风、手绘白板风、手绘技术解释风、电子墨水杂志风、创意杂志风、复古扁平插画风。
3. **规划提纲**。列出每页的角色（封面 / 背景 / 分主线 / 要点 / 对比 / 总结…），复杂任务先用 `todo` 写清单。
4. **为每页写出图提示词**（关键）。见下方"提示词写法"。
5. **调用 `generate_ppt`** 一次传入整套页面。
6. **返回下载链接**。把工具返回的 `download_url` 以 markdown 链接给用户，例如 `[下载 PPT](/download?user_id=...&file=...)`。

## 调用 generate_ppt

```
generate_ppt(
  title="NaPi2b 靶点研究综述",
  style="科研答辩风",
  slides=[
    {"prompt": "<第1页出图提示词>", "notes": "<第1页演讲备注，可选>"},
    {"prompt": "<第2页出图提示词>", "notes": "..."},
    ...
  ]
)
```

- `title` 同时用作文件名。
- `slides` 每项 `{prompt, notes?}`；`notes` 写进 PPT 演讲备注。
- 页数上限 20，出图较慢（每页约 30-60 秒），一次传全。

## 提示词写法（每页 prompt）

用**英文骨架**描述版式（layout、标题栏、分栏、箭头、卡片位置），用**中文原文**写要显示的标题/正文文字，并用引号标出精确文字，例如 `white bold Chinese exactly: "研究背景"`。

铁律（图片模型的坑，务必遵守）：

- **文字尽量精简**，每个字都要正确。中文长句、生僻词、latin 长名（如药名）越多越容易出错，能删就删。
- **不要写十六进制色号**（如 `#003F8F`）——它会被当文字画进图里。颜色只用英文词描述（deep blue / warm red）。
- **不要写"Card 1 / 图1"之类脚手架词**——会被渲染成乱码标签。
- **不要写负向描述**（如"不要浏览器/不要图标"）——图片模型没有负向提示，反而会把它画出来。只写想要的东西。
- 风格和"无水印/无色号/中文清晰"等全局约束由工具统一注入，prompt 里只需专注这一页的内容与版式。

单页示例：

```
Top: a deep-blue title bar with white bold Chinese exactly: "研究背景".
Body: three rounded cards in a row, each a short black Chinese line:
"高表达"、"可内吞"、"肿瘤相关抗原".
Bottom: a thin deep-blue strip with white Chinese: "理想的 ADC 靶点".
```

## 注意

- 生成的图片文字可能有个别 latin/生僻字瑕疵，属图片模型固有局限；追求 latin 严格准确时可提示用户在 PowerPoint 里叠加文本框。
- 用户上传的资料若在沙箱里，用 `terminal` 读；若是图片风格参考，用 `vision_analyze` 提炼后映射到预设风格。
