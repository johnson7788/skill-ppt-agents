# Skill PPT Agents — 让 AI 帮你做 PPT、查论文、搞研究的全能智能体

> **项目地址**：[https://github.com/johnson7788/skill-ppt-agents](https://github.com/johnson7788/skill-ppt-agents)
>
> 基于 Google ADK + DeepSeek 构建，一句话生成整套 PPT，同时能查论文、搜网页、分析文件，还能让非技术用户看懂 AI 的"思考过程"。

---

## 它是什么？

想象一下：你跟 AI 说"帮我做一套 LLM 发展史的 PPT，麦肯锡风格"，它就真的帮你做出来一套视觉统一、排版精致的演示文稿，每页都是一张完整的 16:9 设计图——不是那种丑到不能用的模板填充，而是真正由 AI 逐页"画"出来的幻灯片。

**Skill PPT Agents** 就是这样一款多功能 AI 智能体。它不仅能生成 PPT，还集成了学术论文检索、网页搜索、文件分析、代码执行等一整套研究工具链。更特别的是，它的**旁路解说系统**会把 AI 的每一步思考和工具调用翻译成通俗易懂的中文卡片，让非技术用户也能理解 AI 在做什么。

## PPT 生成：从一句话到一整套幻灯片

这是项目最亮眼的功能。整个流程分四步：

```
用户说"做一套 LLM 发展史 PPT，麦肯锡风格"
        │
        ▼
  ① Agent 规划提纲，为每页写出出图提示词
        │
        ▼
  ② qwen-image 逐页渲染 16:9 整图（每页约 30-60 秒）
        │
        ▼
  ③ python-pptx 组装为 .pptx（含演讲备注）
        │
        ▼
  ④ 返回下载链接，用户直接拿到可用的演示文稿
```

### 12 种预设风格

项目内置了 12 种精心设计的视觉风格，覆盖从学术到商业的各种场景：

| 风格 | 适用场景 |
|:-----|:---------|
| 科研答辩风 | 学术报告、毕业答辩 |
| 麦肯锡风格 | 商业提案、咨询报告 |
| 清爽专业风 | 通用商务场景 |
| 数据仪表盘风 | 数据报告、运营分析 |
| 党政红风格 | 政府汇报、党建材料 |
| 教学课件风 | 课堂教学、培训 |
| 温暖手工风 | 创意展示、团队介绍 |
| 手绘白板风 | 技术分享、头脑风暴 |
| 手绘技术解释风 | 技术文档、架构说明 |
| 电子墨水杂志风 | 文艺内容、杂志排版 |
| 创意杂志风 | 时尚、设计类内容 |
| 复古扁平插画风 | 轻松有趣的演示 |

前端提供下拉菜单，选定风格后自动注入到每页的出图提示词中，无需手动调整。

### 出图提示词的学问

PPT 生成的关键不在于"画"，而在于**怎么写提示词**。项目总结了一套实战经验：

- **英文骨架 + 中文文字**：用英文描述版式布局，用中文写要显示的文字
- **不写色号**：`#003F8F` 会被当成文字画进图里，颜色只用英文词
- **不写负向描述**："不要浏览器"反而会把浏览器画出来
- **文字越精简越好**：图片模型对中文长句和生僻字容易出错

## 旁路解说：让 AI 的工作过程"可读"

这是项目最有创意的架构设计。传统 AI 应用中，用户只能看到最终输出，不知道 AI 中间做了什么。**旁路解说系统**通过三个回调钩子，把整个过程翻译成人类能理解的卡片：

```
┌──────────────────────────────────────────────────┐
│              主 Agent (DeepSeek)                   │
│         思考 → 调用工具 → 分析结果 → 回答           │
└─────────┬──────────────┬──────────────┬──────────┘
          │              │              │
    ┌─────▼─────┐  ┌────▼─────┐  ┌────▼──────┐
    │ 正文回复   │  │ 思考过程  │  │ 工具调用   │
    │ 直接展示   │  │ 翻译解说  │  │ 翻译解说   │
    └─────┬─────┘  └────┬─────┘  └────┬──────┘
          │              │              │
          ▼              ▼              ▼
    ┌─────────┐  ┌────────────┐  ┌────────────┐
    │ 最终答案 │  │ 🧠 思考卡片 │  │ 🔬 工具卡片 │
    │ 流式展示 │  │ 通俗中文    │  │ 友好标签    │
    └─────────┘  └────────────┘  └────────────┘
```

| 回调钩子 | 触发时机 | 做什么 |
|:---------|:---------|:-------|
| `before_tool_callback` | 工具执行前 | 告诉用户"即将做什么" |
| `after_tool_callback` | 工具执行后 | 告诉用户"做了什么，结果如何" |
| `after_model_callback` | LLM 每次响应后 | 把思考过程翻译为通俗说明 |

设计原则很明确：**解说只翻译过程，绝不触碰正文输出；解说失败静默捕获，绝不影响主 Agent。**

来看一个真实的查询流程——用户问"对比 RAG 与长上下文窗口在知识密集型任务上的优劣"：

![Agent 输出示例](docs/Agent输出示例.gif)

### Agent 的工作过程

**思考过程**（旁路解说翻译后）：

```
🧠 根据研究问题制定检索策略
🧠 分析主要实验结果与评测指标
```

**工具调用过程**（解说卡片）：

```
[1]  📖 加载技能指导 …
       读取论文检索技能的详细分步指导

[2]  🔧 执行检索脚本 …
       正在执行 arXiv 论文检索

[3]  🔧 执行检索脚本 - 完成 ✓
       脚本执行成功，stdout 输出 28,114 字符
```

**最终回答**（节选）：

> **RAG（检索增强生成）** 在推理时从外部知识库检索相关片段拼接到提示中，知识可随时更新、单次上下文成本低；**长上下文窗口** 则将全部材料直接放入模型上下文，省去检索环节、保留完整篇章结构。
>
> | 维度 | RAG | 长上下文窗口 |
> |:-----|:----|:-------------|
> | 知识更新 | 实时，无需重训 | 受窗口与训练数据限制 |
> | 推理成本 | 低（只注入相关片段） | 高（随长度平方增长） |
> | 长程依赖 | 受检索召回影响 | 完整保留篇章结构 |
> | 典型失败模式 | 检索召回不全 | lost in the middle |

## 人在回路：AI 也会"反问"

当用户需求不明确时，Agent 不会自己瞎猜，而是主动向你提问澄清。比如你说"帮我对比这两个方向的代表性工作"，Agent 会问：

```
你想对比哪两个方向？
  ○ RAG vs 长上下文
  ○ MoE vs Dense
  ○ 扩散模型 vs 自回归
  ○ [自由输入...]
```

你回答后，Agent 无缝续接同一会话继续执行——整个过程就像和一个真人研究助手对话。

技术上，这通过 Google ADK 的 `LongRunningFunctionTool` 实现：工具调用后挂起等待，前端渲染澄清卡片，用户回答通过 `POST /chat/answer` 回灌同一 session。

## 多租户沙箱隔离

当多个用户同时使用时，每个人执行的命令和代码都在**独立的沙箱**里运行，文件、进程、已安装的包互不干扰。

- **预热池**：启动时预建空闲沙箱，首次使用即时分配
- **每租户独占**：同一用户复用同一沙箱，活跃时自动续期
- **闲置回收**：超时自动回收，防止资源泄漏
- **未启用零依赖**：关闭沙箱时回退到本地执行，行为不变

## 快速上手

### 本地开发（3 步搞定）

```bash
# 1. 装依赖
cd backend && uv sync
cd ../frontend && npm install

# 2. 配置 API Key
cp backend/env_example backend/.env
# 编辑 .env，填入 DEEPSEEK_API_KEY（必填）和 DASHSCOPE_API_KEY（PPT 生成需要）

# 3. 一键启动
./start.sh
# 后端 :8686 + 前端 :3686
```

### Docker 一键部署

```bash
# 配好 .env 后
./deploy.sh
# 完整流程：环境检查 → git pull → docker compose up → 健康检查
```

## 项目亮点总结

1. **图片型 PPT 是真正的"画"出来的**——不是模板填充，而是 AI 逐页生成的视觉统一设计图，12 种风格覆盖学术到商业全场景

2. **旁路解说是首创的"可解释 AI"实践**——三个回调钩子把 Agent 的内部过程翻译成人类能理解的卡片，让非技术用户也能看懂 AI 在做什么

3. **人在回路不是噱头**——Agent 真的会在需求不清时主动反问，用户回答后无缝续接，交互体验接近真人助手

4. **技能系统可插拔**——arXiv 检索、网页搜索、PPT 生成都是独立技能，新增技能只需一个目录 + SKILL.md + 脚本

5. **生产级设计**——多租户沙箱隔离、SSE 响应缓存、会话日志、版本回滚、LLM 驱动的智能优化，不是 demo 而是能用的系统
